# ps1/ — PlayStation platform layer (Sonic Mania)

The psyqo side of the port: the app that runs the RSDKv5 engine, and the hardware drivers the engine's PS1 backends
(`RSDKv5/RSDK/{Graphics,Audio,Input,Scene}/PS1`) call. Copied from `RSDKv3-ps1` (Sonic CD, with the real-hardware
fixes of `../../docs/31`) and adapted per phase (`../../docs/32`). Each file's header describes it.

`loading_icon.h` is generated from `PS1/Memcard icons/sonic-mania-loading.gif` (4 frames of 48x48, 15 colours) by
`tools/loading/build_icon.py`; `memcard_icons.h` from `PS1/Memcard icons` by `tools/memcard/build_icons.py`.

| File | Role |
|---|---|
| `rsdk5_main.cpp` | the psyqo application: engine init, one ProcessEngine a vblank, the 30 fps cap / Frameskip steps |
| `rsdk5_objects.inc` | generated by `tools/gen_overlays.py plan`: the resident object list |
| `ps1_limits.h` | limits the engine and the game share (entity slots) |
| `overlay.cpp` | loads a stage folder's code overlay (`Data/PS1Ovl/`) at STG's top, flushes the I-cache |
| `gpu_chain.cpp/.hh`, `gpu_chain_raw.hh` | the DMA-chained renderer: one 60 KB arena, fragments; the psyqo-free interface for the engine |
| `vram.cpp/.hh` | VRAM uploads (and GDB readback) for the engine side |
| `gte3d.cpp/.hh` | Scene3D's projection on the GTE (RTPT) |
| `s3d_faces.s`, `s3d_blend.s`, `floor_quads.s` | UFO stage hot loops in assembly: gouraud faces, keyframe blend, floor tile quads |
| `cdrom_fs.cpp` | ISO9660 reads behind the `<stdio.h>` FILE API, file index |
| `cdrom_stream.cpp/.hh` | continuous sector streaming (STR video) |
| `xa_music.cpp/.hh` | CD-XA music (`Data/Music/Music.xa`) through the drive's decoder |
| `spu.cpp/.hh` | SPU driver (ps1-bare-metal model): SFX banks, voices |
| `fmv.cpp/.hh`, `video.cpp/.hh`, `mdec.cpp/.hh`, `video_ops.hh` | STR video player (CPU-driven MDEC), linked into the overlays that play videos and reached through `video_ops.hh` |
| `loading.cpp/.hh`, `loading_icon.h` | loading indicator during blocking loads (waits while a GPU DMA runs) |
| `memcard.cpp/.hh`, `user_card.cpp`, `memcard_icons.h` | memory card saves: psyqo's card file system, Mania's user file on the card, the save icon |
| `irq_guard.cpp/.hh` | lost-IRQ guard (real-hardware fix) and CD orphan-answer drain |
| `pc_sampler.cpp` | `make SAMPLE=1`: CPU time by instruction (root counter 0) |
| `perf_hud.cpp` | `make PERF_HUD=1`: frame-timing numbers in the corner |
| `memcard_test.cpp` | `make MEMCARD_TEST=1` self-test |
| `platform_test.cpp` | `make PLATFORM_TEST=1`: the phase 0 smoke test of this layer |
| `libc/` | freestanding C / C++ shims (string, math, stdio, time, containers, `new` guard) |
